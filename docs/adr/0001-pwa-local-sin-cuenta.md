# PWA local, sin cuenta

Bienestoy es de una sola usuaria y un solo dispositivo: el trabajo diario es marcar la sesión de hoy, no sincronizar vidas. v1 es una PWA (Vite + React + TypeScript) con datos en el navegador y export/import JSON. No hay cuentas, nube ni app nativa: auth y stores retrasarían el bucle y el export cubre el backup que una app personal necesita.
